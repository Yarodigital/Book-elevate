ELEVATE LUXURY TRANSPORTATION - SIMPLE STATIC WEBSITE

WHAT'S INCLUDED
- index.html: the entire website (no JavaScript and no outside services)
- portrait.png: the graphic shown in vertical / portrait orientation
- landscape.png: the graphic shown in horizontal / landscape orientation

HOW TO PUBLISH
1. Unzip Elevate-Website.zip.
2. Upload index.html, portrait.png and landscape.png together into the folder your domain serves (often public_html on GoDaddy; it might be another configured folder).
3. Open your domain in a browser. Turning your phone or tablet changes the graphic automatically.

IMPORTANT
- Upload the three files as separate files in the SAME web folder. Do not upload only the .zip unless your host extracts it.
- File names are case-sensitive on many hosts. Keep the names exactly as shown.
- The image is kept completely visible without cropping. Depending on the screen's shape, narrow empty margins may appear. This is intentional so no wording or contact info is cut off.
- There are no menus, forms, scripts, online APIs or other moving parts.
- This is an image-only advertisement. The displayed phone number is readable but not a clickable text link.
- The supplied source graphics are 864 x 1536 (portrait) and 1536 x 1152 (landscape). The website displays them at their original visual quality; it cannot create additional true photographic detail.

TO SWAP GRAPHICS LATER
Replace portrait.png or landscape.png with a new image using the SAME filename. If an old version remains visible, refresh the browser or clear the site's cache.
